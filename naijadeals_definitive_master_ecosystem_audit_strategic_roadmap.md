## 2. Missing Features & Capabilities
Critical process gaps identified during architecture validation.

*   **Logistics**: **Reverse Logistics Hub (Returns Engine)** — Currently missing a unified "First Mile" returns pipeline for commerce trust.
*   **Mobility**: **Driver Multi-Vertical Switching** — Seamless UI for drivers to transition between Courier (Send), Delivery (Eats), and Passenger (Drive) modes.
*   **Commerce**: **B2B Bulk Negotiation AI** — Automated RFQ response system for high-volume wholesale transactions.
*   **Identity**: **Verification-as-a-Service (VaaS)** — External API for 3rd party sites to use NaijaDeals Trust Scores.
*   **Edge Cases**: **Offline Transaction Verification** — QR-based proof-of-service for areas with <2G connectivity.
