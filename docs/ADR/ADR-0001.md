# ADR-0001: Use Prisma as the ORM for NaijaDeals

## Status

Accepted

## Context

NaijaDeals requires a TypeScript-first data access layer that supports PostgreSQL, enforces schema discipline, enables safe migrations, and remains maintainable as the platform grows across multiple product-line domains. The data layer must support strict typing, relational integrity, and evolution without duplication or ad-hoc SQL.

## Decision

Use **Prisma** as the ORM for all NaijaDeals services that interact with PostgreSQL.

## Alternatives Considered

| Alternative | Reason Not Chosen |
| --- | --- |
| TypeORM | Decorator-heavy API, less consistent migration tooling, and larger runtime surface area than needed |
| Sequelize | Active record model encourages tight coupling; weaker TypeScript inference |
| Drizzle | Promising but younger ecosystem; migration and introspection maturity did not meet enterprise governance needs at decision time |
| Raw SQL | Unmaintainable across multiple domains; removes compile-time safety and migration discipline |

## Consequences

### Positive

- Type-safe database queries generated from a single schema definition.
- First-class migration tooling via `prisma migrate`.
- Strong PostgreSQL support and introspection capabilities.
- Clear separation between schema, migrations, and generated client code.
- Excellent integration with the Next.js / Node.js / TypeScript stack.

### Negative

- Generated client adds a build-time dependency.
- Migrations must be reviewed as code, not as generated afterthoughts.
- Schema changes require coordination across product-line modules sharing the same database.
- Prisma's migration system is opinionated; custom SQL migrations require careful handling.

## Implementation Notes

- Schema is defined in `prisma/schema.prisma`.
- Migrations live in `prisma/migrations/` and follow the migration discipline in `DATABASE_PLAYBOOK.md` and `DATABASE_STANDARDS.md`.
- The generated Prisma client is not committed to version control.
- All database access must go through the Prisma client or governed repositories, not raw SQL or direct connections.
