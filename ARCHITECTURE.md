# PROJECT_RULES.md

## Description

PROJECT_RULES.md is the governing engineering policy document for the NaijaDeals Super Ecosystem.

This document defines the mandatory rules, engineering standards, development philosophy, implementation requirements, coding expectations, security policies, and architectural principles that every contributor must follow.

It applies equally to:

- Human developers
- AI coding assistants
- Contractors
- Freelancers
- Automation tools
- Future engineering teams

PROJECT_RULES.md is the operational "constitution" of the NaijaDeals codebase.

It establishes what developers are permitted to do, what is prohibited, and the standards that must be maintained throughout the lifecycle of the platform.

This document is intended to ensure that all code produced for NaijaDeals remains:

- Production-ready
- Modular
- Secure
- Scalable
- Maintainable
- Well documented
- Consistent with the long-term architecture of the ecosystem

Every contributor is expected to review and understand PROJECT_RULES.md before making any modification to the repository.

Where there is any conflict between implementation decisions and PROJECT_RULES.md, this document shall take precedence unless the Project Owner provides written approval for an exception.

Failure to follow these rules may result in rejected pull requests, rejected milestones, required rework, or removal from the project.

PROJECT_RULES.md should be treated as the official engineering policy manual for the NaijaDeals Super Ecosystem.
