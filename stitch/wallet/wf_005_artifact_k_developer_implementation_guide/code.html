balance

DOUBLE_ENTRY INTEGRITY

Architectural Mandate

RULE_01

Atomic Transactions: No ledger entry shall exist without a matching contra-entry within the same database transaction boundary.

RULE_02

Immutability: All entries are 'append-only'. Corrective actions must be performed via new reversing entries (Credit/Debit pair).

RULE_03

Sum-Zero Check: Every 30 seconds, a background worker verifies that Σ(Debits) - Σ(Credits) = 0 per Shard.

CRITICAL: Failure to maintain zero-sum triggers immediate system-wide HALT and PagerDuty alert.
