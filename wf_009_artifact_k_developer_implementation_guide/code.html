## CONTEXTUAL_RULES

  • Messaging: All payloads must be signed using SHA-256 HMAC via the Auth service bridge.
  • Translation: Use SVC-03 for asynchronous batching to avoid blocking the main UI thread.
  • Moderation: Failure in the moderation workflow (WF_ID: 8829) results in a hard-lock of the conversation until human review.
